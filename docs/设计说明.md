# 交易反欺诈数据挖掘与风险决策设计

## 定位

这是完整版反欺诈项目的独立求职项目版本，面向数据挖掘岗位，保留一次完整的“不平衡分类 -> 时间验证 -> 风险阈值 -> 成本决策”闭环，同时控制目录和代码规模，便于候选人独立解释。

## 保留的能力

- 默认读取公开信用卡 CSV；没有数据时只允许显式运行固定种子的合成数据自检。
- 按交易时间划分训练、验证、测试集，避免随机切分带来的时间泄漏。
- 用类别加权逻辑回归做基线，用类别加权 XGBoost 做提升模型。
- 用验证集选择风险阈值，测试集只做冻结后的最终评估。
- 将相对时间用于探索画像，但不伪装成真实钟点特征；金额对数进入模型。
- 以 AP、ROC-AUC、Precision、Recall、F1、混淆矩阵和成本矩阵解释结果。
- 使用 XGBoost 原生特征重要性，避免 SHAP 成为运行前提。
- 提供中文 Streamlit 看板和少量自动测试。

## 明确排除

本版本不包含 API、模型发布、依赖哈希、PSI 监控、客户/终端历史特征、队列回放、SQL 审计、CI 和多层实验指针。完整版继续保留这些能力。

## 文件边界

`run.py` 负责命令入口；`fraud_model.py` 负责数据、训练、评估和报告；`dashboard.py` 只负责读取报告并展示；`tests/` 只验证时间切分、阈值选择不读取测试标签和成本计算；`docs/简历项目经历.md` 提供可核实的简历表述。

## 验收

`python run.py train --data data/creditcard.csv` 能生成公开数据报告；`streamlit run dashboard.py` 能打开中文结果看板；测试覆盖关键边界；缺少真实 CSV 时页面明确提示合成数据只用于流程自检，不把自检结果写成真实效果。
