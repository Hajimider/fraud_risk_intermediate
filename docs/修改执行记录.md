# 诊断计划执行记录

本轮依据 `docs/项目诊断与修改计划.md` 实施，保留既有未提交改动。

## 实施范围

1. 统一成本参数、修正阈值搜索、逐组重新优化敏感性策略。
2. 用同一冻结模型的训练尾段校准，比较 Platt、Isotonic 和原方案；补充基线、技能分和 ECE。
3. 两类模型使用相同候选预算，在训练内部早停；金额三组消融与误差分析。
4. 将直方图和可靠性分箱写入汇总报告，保留 MySQL 默认；`python run.py demo` 仍需本地 MySQL 服务。
5. 补齐 IEEE 数据接入与防泄漏特征入口；完成真实 590,540 行全量历史特征、成熟目标编码和按相对月滚动实验。
6. 重训 ULB、更新文档与截图、执行回归和独立审查。

- 七张图片由本地Streamlit页面实际渲染；AI页使用正式报告离线摘要，`screenshots.source.json`中的SHA-256与`reports/latest.json`一致。只验证本地渲染，没有验证云端部署。
- README及docs中文Markdown无本机路径/解释器绑定，相对文件链接有效；`git diff --check`通过。
